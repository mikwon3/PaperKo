## PaperKo 1.8.4 — 첫 공개 판

논문·설계기준·시방서·일반 문서 PDF를 **원본 레이아웃을 유지한 채** 한국어(및 다국어)로 번역하는
데스크탑 앱입니다. 번역본을 편집 살린 **PDF**로 만들고, **한글(HWPX)·Word(DOCX)** 로도 저장합니다.

### 이 판의 새 기능

- **온라인 자동 업데이트** — 앱이 시작할 때 새 판을 스스로 확인해(하루 1회, 설정에서 끄거나 특정 판
  건너뛰기 가능) 서명된 릴리스를 받아 자동으로 설치합니다. macOS 는 새 앱으로 교체 후 다시 열고,
  Windows 는 설치 프로그램이 이어받습니다. 릴리스 정보는 Ed25519 서명으로, 설치본은 SHA-256 으로
  검증합니다.
- **AGPL-3.0 공개** — 소스를 [mikwon3/PaperKo](https://github.com/mikwon3/PaperKo)
  에 공개했습니다.

### 담긴 기능

- 레이아웃 보존 번역 PDF (2단/1단·표·그림·수식·절 구조 유지)
- HWPX·DOCX 저장 (완전 오프라인, 표는 실제 표 객체로 복원)
- 일반 문서 모드 — 페이지 범위 배치 번역, 중단·재시작 후 이어받기
- 다국어 (한국어·English·日本語·中文·Español·Deutsch·Français), UI 한/영
- OCR (스캔·이미지 PDF)
- LLM 선택 — OpenAI 호환 서버(vLLM 등)·OpenAI·Anthropic·Gemini API, 또는 번들 llama.cpp 로 오프라인

### 내려받기

| 운영체제 | 파일 |
|---|---|
| macOS 12 이상 (Apple Silicon) | `PaperKo-1.8.4-arm64.dmg` |
| Windows 10 이상 x64 | `PaperKo-1.8.4-amd64-installer.exe` |

설치 파일에 개발자 서명이 없어 처음 열 때 운영체제 경고가 뜹니다. macOS 는 **시스템 설정 › 개인정보
보호 및 보안**에서 "그래도 열기", Windows 는 "추가 정보 › 실행"을 누르세요. 각 파일의 SHA-256 은
아래 manifest 에 있습니다.
