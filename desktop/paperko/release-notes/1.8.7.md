## PaperKo 1.8.7

빌드·배포 도구 정리 판입니다. **앱 기능·번역 동작은 1.8.6과 동일**하며, 새로 받을 기능 변화는 없습니다.

### 바뀐 점 (내부)

- 릴리스를 발행할 때 오래된 판이 쌓이지 않도록, 배포 저장소에 **최신 2판만 유지**하고 그보다 오래된
  릴리스는 자동으로 정리합니다(README 변경 이력도 같이 맞춤).
- 빌드 저장소·경로 이름을 모두 `PaperKo`로 통일했습니다(소스·릴리스·로컬·Windows 빌드 폴더).

### 내려받기

| 운영체제 | 파일 |
|---|---|
| macOS 12 이상 (Apple Silicon) | `PaperKo-1.8.7-arm64.dmg` |
| Windows 10 이상 x64 | `PaperKo-1.8.7-amd64-installer.exe` |

1.8.4 이상을 쓰고 있으면 앱이 시작할 때 이 판을 자동으로 확인해 받습니다. 처음 설치할 때는 개발자
서명이 없어 OS 경고가 뜨며, macOS 는 **시스템 설정 › 개인정보 보호 및 보안**에서 "그래도 열기",
Windows 는 "추가 정보 › 실행"을 누르면 됩니다. 각 파일의 SHA-256 은 아래 manifest 에 있습니다.
